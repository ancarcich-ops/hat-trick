## Summary

Total slugs audited: ~233 (skipping 23 pre-verified, ~15 in untouched ranges plus skips).

### Counts by category

- Hard mismatches: 22
  - rangers-captain, baxter, commander, sir-saint, louie, captain-k, knightro, mountaineer, shasta, bucky, rose-hill-ram, gw-colonial, rhody, spike-drake, reggie-isu, sycamore-sam, tc-uni, drex, vandal, louie-lumberjack, bison-bucknell, rhett-bu, holy-cross-eagle, general-citadel, sammy-cowboy, skyhawk-utm, eddie-cougar (27 total — recount below)
- Label leaks: many — concentrated in MAC/Sun Belt/CUSA/MAAC/CAA/Big Sky/Patriot/SoCon/Southland/OVC/SEC-grid/MVC/A-10/WCC images that share the source-grid title-band format.
- Severe encroachment: 4 (take-flight, wolfie, rocky-mls, timbers-army)
- Cropping issues: 3 (jazz-bear, nordy, commander, king)
- Missing files: 1 (freddy-falcon-bg)

### Notable patterns

- The MLS images (`take-flight`, `wolfie`, `rocky-mls`, `timbers-army`, `king`) appear sourced from a multi-cell grid with neighbor-cell bleed-through.
- The Sun Belt / CUSA / MAAC / CAA / Big Sky / Patriot League / SoCon / Southland / OVC / Drake / Illinois State / Indiana State / Northern Iowa / Holy Cross / McNeese / Skyhawk / Eddie Cougar / BU Rhett / Bucknell Bison / Vandal / Louie Lumberjack images were likely all extracted from a source grid that included team-name title bands, producing systematic label-leak issues at the bottom of each image and (in many cases) appears to have grabbed the wrong cell, producing hard mismatches.
